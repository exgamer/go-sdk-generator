## Установка

Пакет размещён на публичном GitHub — специальной авторизации не требуется.

**Запуск (без установки, привязка к версии)**

```bash
go run github.com/exgamer/go-sdk-generator/cmd/codegen@v0.0.2 init
```

Не добавляет `gosdk-generator` в зависимости целевого сервиса — модуль скачивается только в module cache вызывающей машины.
